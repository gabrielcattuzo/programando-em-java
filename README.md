## 📖 Sobre o repositório

Este repositório reúne projetos e exercícios desenvolvidos durante meus estudos da linguagem **Java**.

Como já possuo experiência com outras linguagens, principalmente **C**, o objetivo deste repositório é aprender e praticar as particularidades do Java, incluindo programação orientada a objetos, organização em classes, coleções, tratamento de exceções e entrada de dados.

Os projetos começam com aplicações simples de terminal e serão expandidos conforme novos conceitos forem estudados.

---

## 📂 Projetos

### 🎓 Sistema de Cadastro e Média de Alunos

Sistema de terminal para gerenciamento básico de alunos.

O programa permite cadastrar alunos, armazenar suas notas, calcular médias e consultar a situação acadêmica.

**Principais funcionalidades:**

* cadastro de alunos;
* armazenamento de nome e RA;
* validação de notas;
* cálculo automático da média;
* classificação da situação do aluno;
* busca de aluno por RA;
* remoção de alunos;
* listagem dos alunos cadastrados;
* validação de entradas.

**Conceitos utilizados:**

`Classes` `Objetos` `ArrayList` `Scanner` `Métodos` `Encapsulamento` `Try/Catch`

### ✈️ Conversor de Unidades

Conversor de unidades desenvolvido para praticar estruturas fundamentais da linguagem Java.

Além das conversões tradicionais, o projeto possui uma seção específica para **unidades utilizadas na aviação**.

**Conversões tradicionais:**

* Celsius ↔ Fahrenheit;
* quilômetros ↔ milhas;
* quilogramas ↔ libras;
* km/h ↔ m/s.

**Conversões de aviação:**

* nós ↔ km/h;
* pés ↔ metros;
* milhas náuticas ↔ quilômetros;
* libras ↔ quilogramas;
* galões americanos ↔ litros;
* Flight Level ↔ pés;
* massa ↔ volume de combustível;
* Jet A / Jet A-1;
* AVGAS;
* densidade personalizada.

**Conceitos utilizados:**

`Classes` `Static` `Scanner` `If/Else` `Switch` `Do/While` `Try/Catch`

## ▶️ Executando os projetos

### Requisitos

É necessário possuir o **Java Development Kit (JDK)** instalado.

Para verificar:

```bash
java -version
javac -version
```

Clone o repositório:

```bash
git clone https://github.com/gabrielcattuzo/programando-em-java.git
```

Entre no diretório:

```bash
cd programando-em-java
```

Depois, acesse a pasta do projeto desejado e siga as instruções presentes em seu respectivo `README.md`.
